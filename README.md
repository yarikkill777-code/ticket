# Редактор прямоугольников

Простой сайт для создания прямоугольников с цветом и двумя числовыми полями.

## Что есть

- Добавление прямоугольников
- Изменение цвета в редакторе
- Два поля для цифр внутри каждого прямоугольника
- Сохранение состояния в браузере
- Экспорт и импорт состояния через JSON

## Как запустить

1. Открой `index.html` в браузере.
2. Или размести проект на GitHub Pages: создай репозиторий, добавь эти файлы и включи Pages.

## Как пользоваться

- Нажми `Добавить прямоугольник`.
- Кликни по прямоугольнику, чтобы открыть панель.
- Выбери цвет и введи два числа.
- Нажми `Экспортировать JSON`, чтобы сохранить состояние и передать другим.

## Замечание про синхронизацию

Статический сайт на GitHub Pages не обеспечивает автоматическую синхронизацию в реальном времени между несколькими пользователями. Для этого требуется отдельный сервер или сервис реального времени (например, Firebase, Supabase или собственный backend).

Если нужно, могу добавить версию с Firebase для совместного редактирования.
